Trilha principal

4 etapas

AI-901 e AI-103 são exames de Azure com Python e Microsoft Foundry. AZ-204 valida o seu stack real e só entra se a empresa for Azure.

  1. Etapa 0

    Ponte de Python

    pré-requisito
    sem exame só o necessário

    Você vem de C#. O objetivo não é virar dev Python, é ler e adaptar os exemplos da Microsoft sem travar.

    Não estudar: orientação a objetos profunda, Django, pandas, ciência de dados. Isso é outro caminho.
    Critério de saída: ler um sample de Foundry e explicar linha por linha sem executar.
  2. Etapa 1

    AI-901 · Azure AI Fundamentals

    certificação
    ~45 min corte 700 40-45% conceitos 55-60% Foundry pt-BR

    Ponto de entrada. Serve para vocabulário e para passar filtro de recrutador. A trilha de estudo é gratuita; só o exame é pago, com valor por país.

    Artefato: script Python que chama modelo no Foundry, recebe resposta em streaming e imprime tokens e latência.
    Critério de saída: passing com folga no Practice Assessment antes de pagar o voucher.
  3. Etapa 2

    AI-103 · Azure AI Apps and Agents Developer Associate

    certificação
    120 min proctored pt-BR exige Python + Foundry

    É a certificação que a Microsoft mapeia oficialmente para o cargo AI Engineer. É a peça central do roadmap.

    Artefato: agente com 3 ferramentas, teto de custo por execução e 20 casos de avaliação com taxa de acerto registrada.
    Critério de saída: explicar sem consultar o que é um eval, por que existe e como medir custo por resposta.
    Traduzir para C#: reimplemente o artefato com Microsoft.Extensions.AI (IChatClient, IEmbeddingGenerator, middleware). O exame é Python; o seu emprego é .NET.
  4. Etapa 3

    AZ-204 · Azure Developer Associate

    condicional
    ~100 min se a empresa for Azure

    Não é IA, é o seu stack. Vale por promoção interna e por credibilidade em conversa de arquitetura. Se a Instramed for on-premise ou AWS, pule.

    Artefato: app .NET publicado com segredos no Key Vault e telemetria no Application Insights.

Prática no trabalho

o que transforma certificado em efetivação

Certificação abre porta. Isto é o que faz alguém confiar em você com um problema em produção.

Um módulo seu

Não uma tarefa: um módulo que você conhece melhor que qualquer pessoa e que, se quebrar, ligam para você.

Um incidente de verdade

Acompanhar um chamado do começo ao fim e escrever o postmortem. Maior aprendizado por hora que existe.

Prova de funcionamento

Build, teste, validação visual com print, e uma linha no MR: o que verifiquei e o que não verifiquei.

Design doc de 1 página

Contexto, alternativas, decisão e risco. Quase nenhum estagiário faz. Quem faz passa a ser convidado para decisão.

Nicho regulatório

LGPD art. 11, RDC 657/2022 (ANVISA), IEC 62304, ISO 14971. Vantagem que nenhum curso de prompt dá.

Uma coisa pública

Post técnico, palestra interna ou contribuição open source. Prova que você sabe explicar.

Armadilhas

as três que custam carreira

Ficar no fácil

A IA é excelente no raso e bem especificado. Só aceitar essas tarefas constrói portfólio raso.

Nunca ser dono de uma falha

Quem nunca quebrou e consertou não tem cicatriz. Sem cicatriz, ninguém confia.

Otimizar volume

Dez features que ninguém revisa valem menos que uma pequena, testada e entendida pelo time.

Teste de seis meses

quatro perguntas

Se as quatro respostas forem "sim", você não está perdendo oportunidades.

  1. 1Existe um módulo que é seu e que o time reconhece como seu?
  2. 2Você já diagnosticou sozinho um problema que a IA não resolveu?
  3. 3Você já escreveu uma decisão técnica que outra pessoa seguiu?
  4. 4Alguém já pediu sua opinião antes de decidir algo?
